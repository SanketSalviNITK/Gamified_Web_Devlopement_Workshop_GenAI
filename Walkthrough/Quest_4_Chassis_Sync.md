# Quest 4: Chassis Sync (3D Avatar)

**Objective**: Load an external 3D Avatar (a `.glb` or `.gltf` file) into your scene using the GLTFLoader.

---

## Step 1: The Meta-Prompt (Use in ChatGPT)
*Copy this prompt, replace the bracketed placeholders with your file paths, and paste it into **ChatGPT**.*

> Act as an expert Prompt Engineer. I need to instruct my local AI coding assistant (Antigravity) to load a 3D model into my Three.js scene. Please generate a highly detailed prompt formatted as a Markdown file. 
> 
> The task is to: Update my `bg.js` file to load an external 3D model using Three.js `GLTFLoader`.
> 
> Make sure the instructions tell the AI to:
> - Import the `GLTFLoader` module from the Three.js CDN.
> - Load my `.glb` file located exactly at `[PATH_TO_YOUR_GLB_FILE]`.
> - Scale the loaded model by a factor of **[SCALE_NUMBER]**.
> - Position the model in the center of the screen.
> - Add logic to the animation loop to make the model slowly rotate on its Y axis.
> 
> Output ONLY the raw markdown content so I can save it directly into a file.

## Step 2: Execute with Antigravity
*Take the markdown generated by ChatGPT and save it in your project folder as `quest_4_instructions.md`. Then, use this simple prompt with **Antigravity**:*

> Read the file `quest_4_instructions.md` and execute the steps to add the 3D model to my scene.

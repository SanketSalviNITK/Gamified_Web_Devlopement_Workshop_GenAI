# Quest 2: Identity Shell (Portfolio)

**Objective**: Generate a highly styled, modern, single-page web portfolio using pure HTML and CSS (no external frameworks).

---

## Step 1: The Meta-Prompt (Use in ChatGPT)
*Copy this prompt, replace the bracketed placeholders with your preferences, and paste it into **ChatGPT**.*

> Act as an expert Prompt Engineer. I need to instruct my local AI coding assistant (Antigravity) to build a web page. Please generate a highly detailed prompt formatted as a Markdown file. 
> 
> The task is to: Write a single-file `index.html` containing a responsive personal portfolio.
> 
> Make sure the instructions tell the AI to:
> - Use a **[CHOOSE_COLOR_THEME]** color theme.
> - Implement a modern 'glassmorphism' design style using pure CSS.
> - Include sections for 'About Me', 'Projects', and 'Skills'.
> - Ensure NO external CSS frameworks (like Tailwind or Bootstrap) are used. 
> - Keep the CSS entirely inside the `<style>` tag.
> 
> Output ONLY the raw markdown content so I can save it directly into a file.

## Step 2: Execute with Antigravity
*Take the markdown generated by ChatGPT and save it in your project folder as `quest_2_instructions.md`. Then, use this simple prompt with **Antigravity**:*

> Read the file `quest_2_instructions.md` and execute the coding plan exactly as described to build my index.html.

**Objective**: Initialize a local repository, create a foundational project file, and push the codebase to a remote GitHub repository.

---

## Step 1: The Meta-Prompt (Use in ChatGPT)
*Copy this prompt, replace the bracketed placeholders with your own information, and paste it into **ChatGPT**. This will force ChatGPT to act as a Prompt Engineer and generate a highly detailed set of instructions.*

> Act as an expert Prompt Engineer. I need to instruct my local AI coding assistant (Antigravity) to complete a terminal task. Please generate a highly detailed prompt formatted as a Markdown file. 
> 
> The task is to: Give me the terminal commands to initialize a git repository, add a simple `README.md` file about my project called **[YOUR_PROJECT_NAME]**, and push it to a new GitHub remote at **[YOUR_GITHUB_REPO_URL]**.
> 
> Make sure the instructions include:
> - Exact terminal commands to run.
> - A brief sentence for Antigravity to write inside the `README.md`.
> 
> Output ONLY the raw markdown content so I can save it directly into a file.

## Step 2: Execute with Antigravity
*Take the markdown generated by ChatGPT and save it in your project folder as `quest_1_instructions.md`. Then, use this simple prompt with **Antigravity**:*

> Read the file `quest_1_instructions.md` and execute the steps exactly as described.

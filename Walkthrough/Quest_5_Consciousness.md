**Objective**: Implement a simple Javascript-based chatbot interface fixed to the bottom corner of your portfolio.

---

## Step 1: The Meta-Prompt (Use in ChatGPT)
*Copy this prompt, replace the bracketed placeholders with your desired logic, and paste it into **ChatGPT**.*

> Act as an expert Prompt Engineer. I need to instruct my local AI coding assistant (Antigravity) to build a chatbot component. Please generate a highly detailed prompt formatted as a Markdown file. 
> 
> The task is to: Create a sleek chatbot UI and the accompanying javascript logic to answer user questions.
> 
> Make sure the instructions tell the AI to:
> - Inject the HTML/CSS for a chat window fixed to the bottom right of `index.html`. It should match my existing cyber-glassmorphism theme.
> - Create a new file called `chatbot.js` (and link it) that handles the logic.
> - The javascript must read the user's input, display it in the chat UI, and respond instantly with predefined answers using regex keyword matching.
> - Specifically, if the user asks about **[TOPIC_1]**, the bot should respond with "**[ANSWER_1]**".
> - Ensure the chat window auto-scrolls to the bottom when new messages appear.
> 
> Output ONLY the raw markdown content so I can save it directly into a file.
